# Hecole.Mediator v1.2.0 — Correção de validação assíncrona + Multi-targeting .NET 8 / .NET 10

## PT-BR

### O que foi corrigido

O `ValidationBehavior` chamava `Validate()` (síncrono) em vez de `ValidateAsync()`.
Isso fazia com que validators usando `MustAsync()` do FluentValidation tivessem suas
regras assíncronas **ignoradas silenciosamente** — dados inválidos passavam pela
validação sem erro.

Essa versão corrige o problema: o `ValidationBehavior` agora usa `ValidateAsync()`
com `Task.WhenAll`, propagando corretamente o `CancellationToken`.

### Novo: suporte a .NET 10 via multi-targeting

O pacote agora é publicado com suporte a **`net8.0`** e **`net10.0`**.
O NuGet resolve automaticamente o target correto para o seu projeto.
Consumidores em .NET 8 continuam funcionando sem alteração;
consumidores em .NET 10 ganham as otimizações nativas da plataforma.

### Preciso alterar meu código?

**Não.** Todas as mudanças são 100% retrocompatíveis. Basta atualizar o pacote.

### Como atualizar

```bash
dotnet add package Hecole.Mediator --version 1.2.0
```

### O que mais mudou

- Multi-targeting: `net8.0` e `net10.0` no mesmo pacote NuGet
- Adicionado projeto de testes unitários com cobertura completa (24 testes, 100% aprovados em ambos os targets)
- Adicionada XML documentation em todas as interfaces e classes públicas
- Criado CHANGELOG.md seguindo Keep a Changelog

Veja o [CHANGELOG completo](./CHANGELOG.md) para mais detalhes.

## EN

### What was fixed

The `ValidationBehavior` was calling `Validate()` (synchronous) instead of
`ValidateAsync()`. This caused validators using FluentValidation's `MustAsync()`
to have their asynchronous rules **silently ignored** — invalid data would pass
validation without any error.

This release fixes the issue: `ValidationBehavior` now uses `ValidateAsync()`
with `Task.WhenAll`, correctly propagating the `CancellationToken`.

### New: .NET 10 support via multi-targeting

The package is now published with support for both **`net8.0`** and **`net10.0`**.
NuGet automatically resolves the correct target for your project.
Consumers on .NET 8 continue to work without any changes;
consumers on .NET 10 get native platform optimizations.

### Do I need to change my code?

**No.** All changes are 100% backwards compatible. Just update the package.

### How to update

```bash
dotnet add package Hecole.Mediator --version 1.2.0
```

### What else changed

- Multi-targeting: `net8.0` and `net10.0` in the same NuGet package
- Added unit test project with full coverage (24 tests, 100% passing on both targets)
- Added XML documentation on all public interfaces and classes
- Created CHANGELOG.md following Keep a Changelog

See the [full CHANGELOG](./CHANGELOG.md) for details.
